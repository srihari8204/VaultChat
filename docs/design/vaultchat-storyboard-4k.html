Section B

The Universal File Viewer

Word, Excel, PowerPoint, PDF, text, Markdown, CSV, JSON, XML, HTML, images (JPG · PNG · GIF · SVG · WEBP), video (MP4 · MOV · MKV), audio (MP3 · WAV), archives (ZIP · RAR · 7Z), code and logs — every file a chat can carry renders natively inside VaultChat. No external application ever opens. Nothing requires a download.
B1A file arrives
screen pending — 07-files-in-chat.html
Every format shared into a chat opens in place. The side panel indexes all supported types — documents, data, media, code, archives.
B2Word — book mode
screen pending — 08-word.html
Two-page book reading with single-page and continuous-scroll modes, contents, bookmarks, comments, tables, hyperlinks, headers, footers, search, zoom, themes, and reading progress.
B3Excel — native grid
screen pending — 09-excel.html
Sheets, formula inspection, freeze panes, filters, sorting, conditional formatting, cell comments, pivot tables, charts, and hidden-sheet awareness.
B4PowerPoint — presenter
screen pending — 10-powerpoint.html
Presenter mode with next-slide preview, speaker notes and timer; slide sorter, thumbnails, animations, embedded video, fullscreen and zoom.
B5PDF — annotate & sign
screen pending — 11-pdf.html
Highlight, draw, comment, fill forms, sign digitally, bookmark, and search — including OCR text found inside scanned pages.
B6Images — compare & inspect
screen pending — 12-image.html
Zoom, rotate, slideshow and fullscreen, plus a draggable before/after compare and full EXIF metadata. JPG, PNG, GIF, SVG and WEBP.
B7Video player
screen pending — 13-video.html
Chapters, subtitles, playback speed, frame-preview scrubbing, picture-in-picture and landscape fullscreen. MP4, MOV, MKV.
B8Audio — waveform
screen pending — 14-audio.html
A real waveform with bookmarks pinned to moments, playback speed, and a live speaker-labelled transcript. MP3, WAV.
B9Archives — browse inside
screen pending — 15-archive.html
ZIP, RAR and 7Z open as a browsable tree with previews — inspect and pull single files without extracting anything.
B10Code, data & logs
screen pending — 16-code-data.html
Syntax-highlighted code, JSON trees, XML, Markdown, CSV and live-tail logs with severity — read-only copies straight from the vault.
B11The Bookshelf

Everything ever shared, in one place: Recent, Pinned, Favorites, Shared with me, Downloads, Collections and Folders.
Section C

Reading Mode

When a message is too large to read comfortably as a bubble, VaultChat offers it as a page instead. Readers get typography, structure and focus — and can flip back to chat view at any time.
C1A long message lands
screen pending — 18-reader-detect.html
VaultChat detects content too large for comfortable chat viewing and offers Reader — or keep it as chat. Your choice is remembered.
C2The message as a page
screen pending — 19-reader.html
Cover title, reading time and page count, then real typography: headings, lists, tables, images, code, links, highlights — with contents, search, progress, copy, share, print and Export PDF. Switch Chat ⇄ Reader any time.
C3Make it yours
screen pending — 20-reader-settings.html
Dark, Light, Sepia and AMOLED themes; Serif, Sans and Monospace faces; text size, line spacing, margins; continuous scroll or book pages.
Section D

Everywhere features

Three surfaces that hold the whole product together: one search across every chat and every file format, a first-class offline vault, and the security controls wrapped around each shared file.
D1Search everywhere
screen pending — 21-search.html
One query sweeps chats, Word, Excel, slides, PDFs (incl. OCR), images, video and audio transcripts, and raw files — on an encrypted, on-device index.
D2The offline vault
screen pending — 22-offline.html
Downloaded, sync-pending and cloud-only states per file; a visible sync queue; edits merge conflict-free on reconnect.
D3Vault controls
screen pending — 23-security.html
End-to-end encryption, a sandboxed viewer, view-only sharing, expiring files, disabled downloads, and per-viewer watermarks.
