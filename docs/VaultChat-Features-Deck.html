Under the hood

Built to WhatsApp / Signal scale

The features above sit on a production-grade backend that's already live in prod (migration 035), with the high-scale stack wired and validated on staging.

  • End-to-end encryptionX3DH + Double Ratchet, 47/47 self-tests, gated by E2EE_ENABLED
  • Local-first renderingexpo-sqlite cache → instant open + delta sync (?after=cursor)
  • Realtime fan-outSocket.IO + Redis adapter, user rooms, emitToUid
  • Durable message busKafka (KRaft) producer + fan-out worker
  • Object storageR2 / MinIO presigned upload/download (S3 SDK)
  • Postgres + RLSrow-level security, ledgered migrations, pool tuning
  • Push w/ self-healingretry + dead-token pruning
  • Docker substratecompose: pg · redis · kafka · minio · api · fanout-worker
client SQLite⇄ Express API⇄ Postgres + RLS· Redis· Kafka· R2/MinIO· Ollama LLM
