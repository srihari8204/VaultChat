Enter the log token

Paste the server's LOG_TOKEN into the field in the header (it lives in /etc/vaultchat-logs.env on the box). The token is kept only in this browser and sent over HTTPS with each request.

If the token is right and this still shows: check the log service — systemctl status vaultchat-logs.
